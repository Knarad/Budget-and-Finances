Data and Settings

Import from the workbook

Reads Enter Transactions, Accounts, Categories and Rules, and Budget from the Excel file on this device and replaces all data in the app with it. The file is read in your browser and is never uploaded to GitHub.

Use "Import the workbook report only" to refresh the Workbook report section without touching any transactions, accounts, budget, or settings.

Export for the workbook

Creates an Excel file with the columns Date, Account, Amount, Description, Category, To account, and Notes. Paste its rows below the last filled row on Enter Transactions.
